# Wikipedia AI Q&A Tool

This is a Python app that lets users query Wikipedia articles and receive real-time, AI-generated answers using OpenAI's API.

## Features
- AI-powered Q&A over any Wikipedia article
- OpenAI API integration
- Real-time interaction in terminal (or GUI if you added one)

## Technologies Used
- Python
- OpenAI API
- Wikipedia Library
- dotenv for secure key management


## Setup
1. Clone the repo
2. Add your `.env` file with your OpenAI API key
3. Run `python AI_works.py`

## Notes
This was a personal learning project to explore LLMs and prompt engineering.
